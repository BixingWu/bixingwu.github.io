# 加密分享组会网页

将 `tools/slides-template.html` 复制到网站仓库外，在副本中编辑报告。也可以使用其他可信的独立 UTF-8 HTML。将图片、字体和音视频嵌入文件，将 CSS 和 JavaScript 写在内联标签中，确保断网时也能播放。普通论文网址可以作为读者主动打开的链接。脚本会检查常见的独立资源引用，包含动态脚本的报告仍需自行断网预览。

使用 Node.js 18 或以上版本，在网站仓库中运行以下命令可生成独立随机地址。

```sh
node tools/seal-slides.mjs "/absolute/path/outside/the-site/report.html"
```

终端将显示带共享口令的完整链接。将链接私下保存并交给受邀者。按网站原有流程发布新生成的 `content/slides/<id>/index.md` 与 `deck.bin`。标题统一为 `Shared slides`，Hugo 会将页面排除在列表和站点地图外。原稿文件名、标题和口令均不会写入这两个文件。

同一研究项目也可以使用固定路径。以下命令创建 `/GroupMeeting/Ocula/`。项目名公开且区分大小写，可使用字母、数字和内嵌连字符，以字母开头。入口 `/GroupMeeting/` 只提供打开私下分享链接的提示。

```sh
node tools/seal-slides.mjs --project Ocula "/absolute/path/outside/the-site/report.html"
```

同一项目的下一份报告使用 `--replace`。发布整个 `content/GroupMeeting/Ocula/` 的变更，包括上一份密文的移除。每份报告有独立的 ID、密文、共享口令和本机逐页备注。新页面只读取与该 ID 配套的密文。分享新命令输出的链接即可。

```sh
node tools/seal-slides.mjs --project Ocula --replace "/absolute/path/outside/the-site/next-report.html"
```

同一项目同时只能运行一次打包命令。如果进程被强制终止，确认打包器已经退出后，用 `rmdir` 移除错误消息所指的空锁目录，再重新运行。

首次打开时，浏览器在本地用口令解密。在该浏览器中成功解锁后会按报告记住口令，并从地址栏移除口令片段。使用模板制作的报告支持指定起始页，如需从第 2 页开始，将原链接中的 `#p=` 改为 `#2&p=`。在共享设备上可以使用隐私窗口，或使用后清理此站点的数据。在新设备上可使用原始分享链接，也可在页面输入 12 位口令，大小写和分组横线均可忽略。

解锁后，点击页脚的 **Copy share link** 即可复制带口令的完整链接。接收者打开时从封面开始。浏览器限制剪贴板时，页面会显示可手动复制的链接。

每次打包都会重新生成报告 ID、共享口令和 IV。打包器使用 600,000 轮 PBKDF2-SHA256 派生 AES-256-GCM 密钥，密文验证绑定到该报告 ID。持有完整链接或口令与报告地址的人均能阅读并保存明文。重新打包后可分享新链接，下线旧地址可停止该站点继续提供旧密文。接收者此前保存的内容仍由接收者持有。

## 现场记录

点击幻灯最底部的备注栏即可输入问题或建议。每页有自己的文本，在当前设备的浏览器中按报告 ID 保存。换设备、清理浏览器数据或替换项目报告前，可先复制需要保留的文字。
