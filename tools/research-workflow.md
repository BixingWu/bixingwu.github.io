# Bixing 的论文与组会工作流

给 Agent 一份材料和一句方向即可开工。论文网页保存可引用的完整正文，组会页围绕你这次想让听众看到的证据。两者都可以用自然语言指定局部修改。

## 可以直接这样说

| 想做什么 | 给 Agent 的一句话 |
| --- | --- |
| 新论文 | 「把这个论文目录做成公开 Paper，和 HuPER 同款。用最终版正文，首页图用 Figure 2，先给我本地预览。」 |
| 读论文 | 「下次组会读这篇，8 分钟。重点讲 Figure 2 和 Table 3，最后讨论它的评估是否适合我们的任务。」 |
| 汇报实验 | 「用这个目录做 Ocula 组会。先放 baseline 和 ours 的同一个样例，再讲消融。失败视频要保留，训练日志只用来核对数字。」 |
| 修一页 | 「改上次 Ocula 的消融页。表格里保留 baseline 和完整模型，把失败例移到右边。其余页沿用上次。」 |
| 接着讲上次的进展 | 「在上次 Ocula 末尾追加两页。第一页放这周的曲线，第二页放异常样例，用原私链。」 |

可按需要指定听众、时长、图号、页序、不能省略的条件，以及哪些内容交给 Agent 取舍。零散指令直接跟材料一起发就好。较长的项目可放一份私有 `brief.md`，其中只记本场重点与明确的偏好。以后说「沿用上次，改这两处」即可。

## 论文网页

1. 确定稿本版本、公开材料和短网址。例如 HuPER 对应 `/paper/huper/`。核对作者顺序、会议、正文、图注、参考文献和引用信息。
2. 用现有 Hugo 论文模板添加稿件。首页论文卡、Paper 目录和阅读页使用同一份元数据。保留能继续修改的正文与原图。修订已发布论文时沿用原地址，并保留已经被引用的章节、图表锚点。
3. 在本机同时打开首页卡片和全文，检查目录跳转、一处公式或表格、图的放大，以及 BibTeX。准备对外发布时使用已确认公开的稿本。

新建命令、字段、正文格式和本地预览见[论文制作说明](papers.md)。

## 组会 Slides

1. 从你指定的方向出发选证据。读论文时找能解释核心机制的原图，再用一项结果或失败例界定结论。汇报自己的实验时先对齐比较条件，再选曲线、表格或对照样例。时间短就减页，同一个结果尽量只解释一次。
2. 在网站仓库外建立本场目录，例如 `meeting-work/Ocula/2026-11-30/`。短报告可用一个 HTML 文件。需逐页反复改时，使用 `slides/01-method.html`、`slides/02-ablation.html` 等能按名称排序的文件，将原图、短片与数据放在同场目录中。每页用普通 `<section class="slide">` 编写。表用 HTML，图用相对路径，图注和比较条件可直接改字。
3. 用模板组装单文件演示和缩略图。在投影尺寸看图轴、表头及图注，手机上看窄表、宽图和 Notes。按你的反馈只编辑对应源页，运行同一条命令即可重建。
4. 同一场修订或续讲时沿用原私链。末尾可直接追加页。需要插页或重排时，按 `tools/slides.md` 保留旧页的笔记编号。新一场报告另存私有源目录。更新同一项目的线上入口会换口令，并使用独立笔记。若希望两场同时可访问，可为新场次生成独立私链。

组装、本地验收与加密发布见[组会制作说明](slides.md)。[HuPER 可编辑示例](meeting/huper-example.html)展示了封面、方法图、双图比较及结果表。

## 你可以改到哪一层

| 修改意图 | Agent 编辑的位置 |
| --- | --- |
| 「这次先讲负结果，只用六分钟」 | 本场选材与页序 |
| 「第 3 页换原视频，对照组保持同一时间窗」 | 该页 HTML、媒体与图注 |
| 「两列表格只标出相同预算下的比较」 | 本页表格的行列和强调样式 |
| 「以后每次都把表格单位写进表头」 | 共用模板和制作规则 |

默认保留 Paramecium 的白底、黑色题名、灰色小节名及红蓝证据标注。是否需要封面、铺垫、动图或讨论页，由本场材料和你的指令决定。组会阅读页与论文公共网页分别维护。本场对某张图的裁剪、标注或点评仅属于这次报告。
